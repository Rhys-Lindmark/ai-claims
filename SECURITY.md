# Security policy

This repository is an early public prototype and has no supported production release yet.

Please report a vulnerability privately through GitHub's **Security → Report a vulnerability** flow for `Rhys-Lindmark/ai-claims`. Do not include sensitive browsing data in a public issue.

High-priority reports include unintended page-data collection, permission escalation, remote-code execution, analysis-registry spoofing, score-gate bypasses, and injection through page metadata or resolver responses.
